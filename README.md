# TechRise Guestbook

A lightweight, multi-container web application where visitors can sign their name and leave a message. Built with Flask, cached with Redis, and served behind an Nginx reverse proxy.

## Prerequisites

- [Docker Desktop](https://www.docker.com/products/docker-desktop/) (includes Docker Compose)
